# Leap Year Checker 🗓️

## 📌 About the Project
Leap Year Checker is a simple Python project that checks whether a given year is a leap year or not. It uses conditional statements and a loop to allow users to check multiple years.

## ✨ Features
- Check whether a year is a leap year.
- Check multiple years without restarting the program.
- Simple and user-friendly interface.
- Displays the result instantly.

## 🛠️ Technologies Used
- Python 3
- Conditional Statements (if-elif-else)
- While Loop
- Modulus Operator (%)

## ▶️ How to Use
1. Run the Python program.
2. Enter a year.
3. The program will display whether it is a leap year or not.
4. Choose whether you want to check another year.
5. Enter `no` to exit.

## 📷 Example

```text
===== LEAP YEAR CHECKER =====

Enter a year: 2024
2024 is a Leap Year

Do you want to check another year? (yes/no): no

Thank you for using Leap Year Checker!
```
